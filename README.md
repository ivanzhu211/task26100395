# BrightLedger 401(k) 安全港配比验证库

处理单个员工单年的雇主配比结算，并判定增强公式是否在整个整数输入域上
不少于基础公式（安全港合格性认证）。

## 约定

- 金额：整数分；百分比：整数基点（10000 基点 = 100%）。
- 合法年工资：2,500,000 至 50,000,000 分。
- 合法年缴费：0 至 floor(工资 × 10%) 分之间的任意整数。
- 公式 = 若干档（累计缴费阈值 ≤ 1000 基点、严格递增；匹配率 0–10000 基点）
  + 可选年度雇主金额上限。
- 结算规则：各档工资阈值先向下取整到分；缴费依次填档；超过末档不匹配；
  每档金额 × 匹配率后单独四舍五入到分（半分向上）；各档相加后应用年度上限。
- 基础公式：工资前 3% 匹配 100%，接下来至 5% 匹配 50%，无上限。

## API

```python
from brightledger import Plan, Tier, basic_plan, match, certify

plan = Plan(tiers=(Tier(400, 10000),))          # 前 4% 缴费匹配 100%
match(plan, 2_500_020, 125_001)                 # -> 100000（雇主配比，分）
match(basic_plan(), 2_500_020, 125_001)         # -> 100001

result = certify(plan, 2_500_000, 50_000_000)   # 全工资区间认证
result.ok                                       # -> False
result.counterexample                           # salary=2500020, deferral=125001, ...
```

- `match(plan, salary, deferral) -> int`：返回雇主配比金额（分）。
- `certify(plan, salary_min, salary_max) -> CertifyResult`：闭区间上判定。
  合格返回 `ok=True`；否则返回最小反例（工资最小者优先，其次缴费最小者），
  反例可由 `match` 逐分复算。即使只少 1 分也会判定不合格。

## 实现要点

`certify` 不逐个枚举输入域（约 10^14 种组合），而是：

1. 对固定工资，E(d)、B(d) 均为缴费 d 的分段取整线性函数，差值
   f(d)=B(d)−E(d) 是步长 ∈ {−1,0,+1} 的拟周期步行；首个 f(d) ≥ 1 的 d
   由分段周期前缀分析以 O(段数 × 周期) 求得。
2. 工资轴按“任一档阈值发生变化”的事件点切分区间；区间内反例缴费集合
   不变，故区间内最小候选工资为 max(区间起点, 10 × d\*)（缴费上限为
   floor(工资/10)）。按工资升序扫描，首个有效候选即为最小反例。
